# تقدم P03 — قاعدة الفرع والتهيئة والأمن الأولي

التاريخ: 2026-10-29. الفرع: Feature-account-system. المرحلة **غير مكتملة التحقق**؛ يجب تنفيذ اختبارات SQL التسعة قبل اعتبار القاعدة جاهزة أو الانتقال إلى عمليات P04 المالية.

## ما أضيف في الكود

- توثيق U6: قاعدة مستقلة لكل تاجر وفرع، وشركة وفرع محلي وحيدان، دون محدد تاجر عالمي متغير.
- نماذج EF Core و21 جدولاً وMigration للإنشاء وأخرى لحماية التدقيق، مع أسماء الجداول الأصلية واستكمالات معلومة للقيود والتزامن والتوقيت.
- Seed قابل للتكرار دون اختلاق بيانات عميل أو أسعار صرف أو حسابات دخول.
- مالك أولي لمرة واحدة وBCrypt ومنح مطابقة لصلاحيات محددة ومصادقة وتدقيق أوليان. إعداد الشركة والفرع داخل معاملة واحدة.
- أداة HisabTak.Tools للإدارة واتصال يشترط التشفير والتحقق من الشهادة.
- نسخ SQL أصلي مع CHECKSUM والتحقق، واستعادة إلى قاعدة جديدة دون استبدال الأصل؛ يحتاجان اختباراً فعلياً.
- مساعد خادم اختبار بشهادة مثبتة وبيانات اعتماد عشوائية خاصة، ومهمة CI منفصلة؛ لم ينفذا حتى النهاية بعد.

## شرط الاستئناف

حُفظ westcentralus.data.mcr.microsoft.com في مسودة إعدادات البيئة لأن صورة Microsoft الرسمية تحول التنزيل إليه. آخر قراءة للسياسة الحالية لم تشمل المضيف الجديد. يلزم حفظ الإضافة وتطبيقها من إعدادات البيئة، ثم تنزيل الصورة وتشغيل المساعد والاختبارات التسعة.

بعد فتح الاتصال، يشخّص أي خطأ في الحاوية أو الشهادة أو Migrations ويصحح قبل ادعاء النجاح. لا يعوض Mock أو InMemory اختبار SQL الفعلي. لا يبدأ ترحيل P04 فوق قاعدة غير متحققة.
