## حزمة P04.2 الأولى — سلامة الحساب والمجموعة

الربط: REQ-009 وREQ-010 وPOL-05.

- إصلاح مستوى مجموعة الحسابات: يحسب من Code بعد إزالة المسافات، مع حفظ الأصفار البادئة. كان الإدخال ` 00121 ` يحفظ كوداً من خمسة محارف بمستوى سبعة.

- إضافة Account.EnsurePostingAllowed: رفض الحساب غير النشط أو المحذوف أو الموقوف وعملة السطر المخالفة. يطبق على عملة المبلغ الأصلي وليس عملة الأساس المستخدمة للموازنة.
