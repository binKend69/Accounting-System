أذن المستخدم بتأجيل اختبار الطباعة الفعلية؛ لا يعد التأجيل نجاحًا للطباعة، ولا يمنع متابعة التطوير. نجحت حزمة الكوبونات وإصلاح واجهتها في [تشغيل 43696933653](https://github.com/binKend69/Accounting-System/actions/runs/43696933653)، بما يشمل SQL وWindows.

## الكوبونات

اعتمد المستخدم كوبونًا واحدًا دون خصم يدوي. يحدد المسؤول رمز الفرع والعملة والمبلغ الثابت أو النسبة وحد الاستخدام والحد الأدنى والتواريخ، وحساب عميل اختياري للبيع الآجل. يتحقق تاريخ الفاتورة وتاريخ خادم SQL معًا. أساس الحد الأدنى والنسبة هو الأسعار المدخلة قبل الخصم، والضريبة وفق سياسة الفاتورة. المردود يعيد المبلغ بعد الخصم.

المسودة لا تستهلك استخدامًا؛ الترحيل يستهلكه داخل معاملة واحدة. السجل تراكمي ولا يعاد الاستخدام تلقائيًا بعد المردود أو العكس. لتعطيل الرمز استعمل «تعطيل المحدد». لتغيير سطور الفاتورة أزل الكوبون ثم أعد تطبيقه.

## أول حزمة P10

ميزان مراجعة تاريخي عبر Stored Procedure وDapper، بواجهة «ميزان المراجعة»: افتتاحي وحركة وختامي، مع إدراج القيد الافتتاحي في يوم البداية مرة واحدة. خيار عملة الأساس يجمع القيم الدفترية التاريخية، وخيار العملة المفردة يعرض مبالغها فقط؛ لا تستخدم أسعار الصرف الحالية. الحسابات ذات التاريخ المالي تظل ظاهرة عند إيقافها. تغيير المرشحات يمسح النتائج القديمة.

P10 ليست مكتملة: بقي الأستاذ التفصيلي والمتاجرة والأرباح والميزانية وPDF العربي وهوية الطباعة وExcel والاستيراد وسياسة التكرار وقبول المخرجات.

## الترقية والتحقق

توجد ترقيات إضافية للكوبونات والتقرير دون إعادة إنشاء المستخدم أو المنشأة. يراجع التحديث على قاعدة تجريبية. اختبارات FinancialReportIntegrationTests تفحص الافتتاح والعكس والتاريخ والعملة والفرع والصلاحيات، وSqlUiSmoke يفحص شاشة التقرير. نجاح الحزمة السابقة لا يثبت نجاح هذه الحزمة؛ تراجع نتائج CI المرتبطة بآخر commit قبل اعتمادها.
