# تسليم P02 — تأسيس الحل

التاريخ: 2026-10-29. الفرع: `Feature-account-system`. إذن المستخدم U4: بدء المرحلة الثانية بعد مراجعة P01. هذه الحزمة تضم مرجع P01 وأساس P02؛ لا تعني اكتمال النظام المحاسبي.

## مراجعة P01 قبل البدء

يوجد 62 متطلباً لكل منها مصدر ومسؤولية ومرحلة ومعيار AC، مع تغطية أقسام المصدر العشرين. اعتماد اليمن والعملات والضريبة الاختيارية والتسديد بعملة مختلفة والجرد المستمر مسجل.

تفاصيل التقريب والصرف والتقييم والفترات والافتتاحيات وغيرها باقية في سجل القرارات مع بواباتها؛ لم نفترض إجاباتها. لا تمنع هذه التفاصيل إنشاء المشاريع وتسجيل الخدمات، لكنها تمنع اعتبار قواعد مالية جديدة معتمدة ضمن P02.

## القرارات التقنية

- .NET 10 LTS، مع SDK 10.0.403 وnet10.0 للمكتبات وnet10.0-windows للواجهة. مصدر التحقق: [بيانات الإصدار الرسمية](https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json)، التي وصفت القناة بأنها lts وactive ونهاية دعمها 2028-11-14 عند الفحص. الاختيار يحقق متطلب .NET 8 أو أحدث ويوفر دعماً أطول للمشروع الجديد.
- أربعة مشاريع إنتاج وثلاثة مشاريع xUnit، مع إدارة مركزية للحزم وملفات قفل ومصدر NuGet رسمي.
- Shared مؤجل حتى توجد حاجة محددة؛ لا مشروع مشترك افتراضي يجمع مسؤوليات الطبقات.
- حزم Microsoft.Extensions 10.0.14 وCommunityToolkit.Mvvm 8.4.2 وSerilog.Extensions.Hosting 10.0.0 وSerilog.Sinks.File 7.0.0؛ جميع الإصدارات المباشرة في Directory.Packages.props.
- لا تضاف حزم الوحدات المؤجلة كمراجع غير مستخدمة. يراجع [سجل الاعتماديات والتراخيص](dependencies.md) قبل إضافة EF وDapper والتحويل والطباعة وغيرها.
- لا تعديل لسياسات الجرد أو العملات أو الافتتاحيات، ولا إنشاء Migration في هذه المرحلة.

## حدود التسليم والانتقال التالي

تنفيذ أساس P02 مكتمل ومتحقق تقنياً في Linux ضمن الأدلة أعلاه. تأكيد تشغيل النافذة على Windows مطلوب قبل ادعاء أن التجربة التفاعلية تعمل.

في P03 نضيف SQL Server وMigrations وSeed وأمناً أولياً، بعد حسم DEC-005 للعزل والفروع وتثبيت إصدار SQL المستهدف. قبل قواعد P04 نعود إلى القرارات المالية المفتوحة، دون استبدالها بافتراضات في الكود.
