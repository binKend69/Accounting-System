# مصفوفة المتطلبات والتتبع

مصادر S1–S5 ومسؤوليات D/A/I/W معرفة في [خط الأساس](baseline.md). أرقام المراحل P01–P12 معرفة في [خطة التسليم](acceptance.md). لكل صف معرّف قبول مستقل `AC-xxx` يطابق رقمه؛ نص العمود الأخير هو معيار هذا القبول. السيناريوهات التفصيلية `SC-xx` مكملة وليست بديلة عنه.

**الحالة المبدئية عندP01 لكل الصفوف: مخطط، غير منفذ، غير مختبر.** تقدم التنفيذ الحالي موثق لكل متطلب متأثر في [تقريرP02](../development/foundation-status.md)، وبقية المتطلبات تبقى مخططة. المراحل تبين بداية التسليم ومكان اكتماله، ولا تؤخر الصلاحيات أو التدقيق أو النسخ إلى نهاية المشروع. القرارات المفتوحة في [سجل القرارات](decisions.md) تحجب الجزء المتأثر فقط.
